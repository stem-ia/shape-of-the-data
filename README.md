# Shape of the Data

A histogram lab and a data bank for Grade 8 statistics, built for the math team at STEM Innovation Academy.

Live: https://stem-ia.github.io/shape-of-the-data/

- `lab/` The histogram lab (guided pizza exploration, hockey, Pokemon, random samples) with My work, where students save graphs and their own sentences and hand them in as a picture or PDF.
- `bank/` Five raw data sets for students to graph on their own. Add `?key` to the link for the teacher key.
- `teachers/` Teacher guide: links to post, outcome coverage, hand-in and marking.

Each `index.html` is one self-contained file with fonts and data built in. It makes no network requests, sets no cookies and needs no login.

What stays on the device: the lab keeps each topic's graph settings and the student's My work (saved graphs and the sentences they wrote) in that browser's local storage only. Nothing is sent anywhere. Work leaves the device only when the student saves a picture, a PDF or a work file. The Name box goes on the saved file only and is not stored. "Clear this device" wipes everything for the next student.

Built by Ben Wood, Digital Learning Coordinator, STEM Innovation Academy.
