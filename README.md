# Shape of the Data

A histogram lab and a data bank for Grade 8 statistics and probability, built for the math team at STEM Innovation Academy.

Live: https://stem-ia.github.io/shape-of-the-data/

- `lab/` The histogram lab (guided pizza exploration, hockey, Pokemon, random samples).
- `bank/` Five raw data sets for students to graph on their own.

Each `index.html` is one self-contained file with fonts and data built in. It makes no network requests, sets no cookies and needs no login. The lab remembers each tab's graph settings in that browser's local storage only. Nothing is sent anywhere and no names are stored. "Clear this device" resets it for the next student.

Built by Ben Wood, Digital Learning Coordinator, STEM Innovation Academy.
